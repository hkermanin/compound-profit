Compound Interest Calculator DApp

Description:

This application is a dedicated financial tool designed to calculate and display the growth of investments using the compound interest formula. It is built to demonstrate strong competence in handling numerical inputs, implementing complex mathematical logic, and rendering results dynamically to the user. The goal was to create a clean, intuitive interface for a complex financial concept.

Tech Stack:

Framework: React

Build Tool: Vite

Styling: Tailwind CSS

Language: JavaScript (ES6+)


Key Features:

Complex Calculation Logic: Accurately computes compound interest based on three main user inputs.

Input Management: Robust handling and validation of numerical fields (Principal Amount, Interest Rate, Time Period).

Dynamic Results Display: The application instantly updates and presents the calculated future value of the investment.

Modern UI/UX: Utilizes Tailwind CSS to ensure a professional, clean, and responsive user experience across different devices.
